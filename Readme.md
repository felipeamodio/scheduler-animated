# Scheduler Animated

Hi 🖖🏽 this is an **scheduler animated app**, The project was made with React Native using **Expo** and **Typescript**

![Gif Schedule](https://github.com/felipeamodio/scheduler-animated/blob/main/schedule.gif)

## Functionality
The project's functionality is simple, it simulates an **schedule app**, we also can use internationalization between English and Portuguese and finally change the theme to dark or light mode.

## Libs

These are the libs used in the project:
- [React Native Reanimated](https://docs.swmansion.com/react-native-reanimated/)
- [i18n](https://www.i18next.com)
- [Lucide](https://lucide.dev)

## Open and run the project

Clone this repository with **git clone https://github.com/felipeamodio/scheduler-animated** or download the files, and after that:
- run **yarn** or **npm i** to install all depencencies 
- run **npx expo start**
- this project only works with your physical cell phone, so download Expo Go in stores and read the QR-Code with your cell phone that will appear after you run the expo start command in the terminal
